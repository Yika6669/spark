# 南通大学 2026 新生通关宝典 · 永久站部署指南

本目录就是一个**可直接上 Gitee Pages 的静态站**：
- `index.html` = 通关宝典完整页（已内嵌 `qwq001first` 微信二维码，纯前端、无后端依赖）

Gitee Pages 是码云的免费静态托管：国内访问快、稳、常驻 CDN，不会像 CloudStudio 临时沙箱那样空闲被回收。

---

## 方式一：网页上传（不用装 git，最省事）

1. 打开 https://gitee.com ，注册 / 登录（需绑定手机实名）。
2. 右上角「+」→「新建仓库」，仓库名随意（如 `ntu2026-passbook`），**设为公开**，可不初始化。
3. 进仓库 →「文件」→「上传文件」，把本目录的 `index.html` 拖上去，填提交说明，提交。
4. 仓库页 → 顶部「服务」→「Gitee Pages」→ 部署分支选 `master`，部署目录 `/`（根目录）→ 点「启动」。
5. 等几十秒，得到**永久地址**：
   `https://<你的用户名>.gitee.io/<仓库名>/`
   这个链接长期稳定，直接发给新生即可。

## 方式二：git 推送（可让我代劳）

1. 在 Gitee 新建公开仓库（同上）。
2. 把仓库 HTTPS 地址发我，或给我一个 **Gitee 私人令牌**（设置 → 私人令牌，勾 `repo`）。
3. 我帮你执行 `git remote add` + `git push`，推上去后你点一下「启动 Gitee Pages」即可。

---

## 注意事项

- 免费版 Gitee Pages **要求仓库公开**（你的内容本身就是公开资料，无影响）。
- 改内容后重新 push / 重新上传，`Gitee Pages` 会自动更新（偶尔需点一下「更新」）。
- 链接稳定常驻，不会再掉线。
- 若想换域名（如自己的域名），Gitee Pages Pro 支持自定义域名（付费），免费版用 `*.gitee.io` 即可。
